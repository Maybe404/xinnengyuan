「观澜」出自《孟子·尽心上》：「观水有术，必观其澜」——看水要看波澜起伏，才能领会水的气势和本质。我们以此为系统命题：看产业情报如观水，必看证据、政策与版本的起伏，才能把握场站配储机会的气势与本质。

这份说明用大白话讲：观澜是干什么的、你打开以后先点哪、每一页在帮你干什么。不要求你先懂储能行业术语。讲演示环境：https://guanlan.maybe404.com

## 先记住三句话

1. **观澜是研究工作台，不是自动拍板的投资系统。** 它帮你把资料、证据、比较和结论摆清楚，方便讨论下一步要不要做配储论证。它不会、也不应该自动批准投资。
2. **工作按「专题」分开。** 一个专题就是一个要回答的问题。苏浙粤比三省机会，是一套材料；如东论证一个场站，是另一套。换专题等于换桌子，桌上的东西不会混。
3. **有的内容跟着专题就出现，有的要你按一下。** 资料清单、场站列表、能力字段会自己出来。比较图、研究报告、新政策影响分析，需要你点按钮，系统会转一会儿（一个会动的圆），再给出预生成的演示结论。那不是全网实时抓新闻。

## 观澜到底帮谁、帮什么忙

新能源场站发的电，有时中午发得出去、有时发不出，就有人研究要不要在场站旁边配储能。观澜面向战略研究、投资发展、场站技术这些角色，做两件具体的事：

- **比区域**：江苏、浙江、广东，哪里更值得先跟进研究。
- **看场站**：某一个场站如果要配储，功率、时长、条件大概是什么方向。

它不管：工程图纸、投标报价、财务模型算投资回报、法律尽调盖章。那些是后面的专业工作。

## 打开之后屏幕上有什么

左边是导航。上面写着「观澜」。下面是「当前专题」，点它可以换专题或新建。再下面是七个页面：

| 你在左边看到的 | 可以把它想成 |
|---|---|
| 业务专题 | 这一桌要回答什么问题 |
| 情报资料 | 桌上的材料袋 |
| 区域比较 | 三省对照表和场站名单 |
| 深度研究 | 写结论的地方（要生成才会出长文） |
| 报告审查 | 给领导看的预览稿 |
| 动态跟踪 | 来了新消息怎么办、换不换版本 |
| 企业能力档案 | 咱们自己能干到哪一步（研究引用的是快照） |

最底下可以切换深色/浅色，刷新后还在。没有登录框，演示账号写死为张远。

## 几个词，用生活里的说法

**资料**：一篇政策、一张电价表、一份招标公告、一则内部访谈。每份会标明「真实公开」「真实内部」或「模拟」。模拟的是编出来方便演示的，不能当成公司已经核实的资产或合同。

**核验**：人看过原文，判断这条事实能不能当依据。系统不替你判真假。没核验的，后面统计里不能冒充「已核验证据」。

**声量 N 和证据 V**：N 是这段时间登记了多少条讨论/记录；V 是核验过、能当证据的条数。热闹不等于真。系统故意不算「真实率」这种容易误会的百分比。

**建议档位**：不是分数排名。大致是：优先跟进、条件进入、持续观察、暂缓推进。有硬条件没满足，再热闹也不能排到最前。条件不清楚，不能当成「没机会」，只能说还不知道。

**版本**：研究结论会锁在某个版本上，比如 v1.4 已经确认。来了新政，先出 v1.5 待确认，**确认以前桌上仍以 v1.4 为准**。避免「系统自己把旧结论改掉了，领导还不知道」。

## 推荐你按这个顺序走（第一次）

下面按「第一次给别人看」来写。自己摸索也可以跳，但缺资料时，比较图和研究会拦住你。

### 第一步：看清这桌要研究什么

点 **业务专题**。看标题、那一大段「决策问题」、比较范围是不是江苏浙江广东、研究做到哪天截止。下面有资料份数、待核验缺口。这里不用先点任何「开始分析」。

**你要能说出：** 我们在比三省配储机会，不是在批一个投资项目。

### 第二步：翻材料袋

点 **情报资料**。预置专题里，表已经在了。点一行，右边（或弹出层）能看到原文片段。标题旁边有一个「导入资料」——只有这一个，把标题、来源、原文贴进去就能加一条。原文太短不让存，因为空链接不算读过。

**你要能说出：** 材料分真的和演示用的模拟，模拟不拿来充真实声量。

### 第三步：真正看一眼原文并留下核验

在资料里点一条事实，打开 **证据侧栏**。勾几种核验方式（比如对原文、对官方附件），选结果，用自己的话写十个字以上说明，提交。刷新浏览器，这条还在，才算留下了痕迹。

**你要能说出：** 核验是人做的。系统不会因为你点了「分析」就把待核验改成已核验。

现场演示常用电价相关编号（如 M-010）：后面写结论时还能点回来，证明不是空口说。

### 第四步：先看三省和场站，再跑图

点 **区域比较**。省份卡片和场站名单应该已经在——这是跟着专题来的。图表（七维对照、雷达、声量柱）要你点 **运行比较分析**，等圆动画走完。

看的时候记住：雷达是两省对照，**色块面积不是总分**。广东若有硬条件缺口，不会因为「讨论很多」就排到最前。

再点一个场站，比如如东。看功率、容量、时长。没有的数就空着，不要当成 0。场站好不好，不跟着「江苏省排第一」自动继承。

**你要能说出：** 我们在比研究优先级，不是在给全省打一个神秘分数。

### 第五步：让系统写出研究草稿

点 **深度研究**。上面几张小卡片（资料份数、核验、能力版本）是带出来的。正文报告要你点 **开始生成研究报告**。生成过程会经过检索、核对、写稿——演示里用的是预先写好的稿子，不是现场联网把全网翻一遍。

生成后你会看到：三省建议档位、事实/推断/假设分开写、配置方向、下一步行动。点结论里的资料编号，应能回到刚才的原文。

**你要能说出：** 事实有出处，猜测单独标成假设。配置方向是给下一步论证用的，不是施工图。

### 第六步：给领导看的那一页

点 **报告审查**。封面（叫什么、谁负责、哪个版本）跟着专题出现。研究一旦生成过，结论会自动进这一页，不用再点「汇编」。把审查意见写成至少十个字，提交。这是「我们接受这一版的写法」，**不是董事会批准投资**。

觉得不行就退回草稿，已经确认过的正式版不会被这次退回直接抹掉。

### 第七步：来了新政策怎么办

点 **动态跟踪**。上面的历史事件本来就在。针对演示里的江苏分时电价征求意见稿，点 **分析新增资料**。看完影响后注意：确认按钮按下去之前，旧版 v1.4 仍是正式说法。新政还没生效，所以只作为情景，不写进基准。

确认 v1.5 之后，新旧两版都能查。反复点确认，不会再复制出一堆版本。

### 第八步：咱们自己的能力变了，结论跟不跟

点 **企业能力档案**。字段一开始就在，每条有来源和是否模拟。只有你点 **模拟编辑此字段** 之后，才会列出「哪些结论引用了这个字段」。改一项运维能力，不该把无关结论全部改写，也不该偷偷把建议档位改掉还不说明理由。

### 第九步：换一桌，证明没把东西带过去

左边换成 **如东光伏基地增配储能论证**。资料变少、场站变少，没有把苏浙粤那套已确认结论原封搬过来。这是避免「上一个项目的判断污染下一个项目」。

## 各页还藏着什么（备查）

**业务专题**：缺口清单告诉你下一步该核验什么；有正式版本才会强调更新事件。空专题可以载入演示资料包。

**情报资料**：类型筛选、搜索、信源检查表（成功 / 无变化 / 失败要分开写）。点「核验下一条待核验」会自动打开还没核的那条。

**区域比较**：点不同省份卡片切换对照对象。供需两侧是同一观察窗口，不能拿供应商数量去替代项目容量。

**深度研究**：成立条件和退出线要一起看。租赁收益没测算就不计入基准。

**报告审查**：打印请用浏览器打印。本期不导出 Word。

**动态跟踪**：没有已确认研究版本时，可以扫资料，但不会硬造一个空版本来「更新」。

**企业能力**：研究引用的是当时那一版快照，避免有人改档案、旧报告里的数字跟着乱跑。

## 常见卡住

**比较图/研究不出？** 先看本专题有没有资料。空的就导入或载入演示包。研究长文一定要先点生成。

**报告没有结论？** 先去深度研究生成。封面可以先有，正文等研究完成自动带入。

**为什么一进来不是「正在 AI 分析」？** 故意的。清单类信息跟着专题走；分析类你点了才跑，并且会标明是演示流水线。

**模拟资料能当证据吗？** 可以出现在桌上，但统计真实声量时不算，结论里要当假设或情景。

**清了浏览器怎么办？** 演示进度在本地。线上地址还在，预置专题还在，你的核验勾选可能没了，再核一次即可。

**能不能当生产系统用？** 不能。没有完整账号权限、没有真实采集巡检、没有财务引擎。它是给评审和讲解用的工作台演示。

## 给领导的一分钟版

观澜把「场站配储该先看哪、某一站大概怎么配」放在同一套专题里。资料能回到原文，核验留痕，比较不算假总分，新政策先出待确认版、不覆盖已签字的旧结论。系统不自动批准投资。现在看到的是带真实公开政策和模拟业务数据的演示，用来走通流程和口径。

## 1. 整体演示流程（必走）

1. 打开预置专题「新能源场站配储布局研究 · 苏浙粤」，确认范围、截止日、能力版本。
2. 进入情报资料：点资料行打开原文 → 点事实打开证据侧栏 → 填写核验方式、结果、≥10 字说明并提交。
3. 进入区域比较：看三省七维表、雷达、声量 N / 证据 V、供需对照。
4. 点击如东或响水场站，查看功率 / 容量 / 时长、阶段证据；点配置方案进入深度研究。
5. 深度研究阅读档位、事实/推断/假设、配置方向；点 `M-010` 追溯原文。
6. 打开「报告审查」预览封面、摘要、图表要点，填写审查意见，提交待确认版本。
7. 动态跟踪点「分析新增资料（预生成）」，确认 v1.5；确认前 v1.4 仍为正式版。
8. 企业能力档案模拟编辑江苏运维字段，查看受影响结论（旧值 / 新值 / 支撑条件）。
9. 左侧切换到「如东光伏基地增配储能论证」，确认资料与场站被隔离，不带入上一专题结论。
10. 可选：新建专题（弹窗）→ 载入演示资料包 → 再走 2–7。
